# V67 · Mercado y lotes

- La calculadora abre sin el panel grande de Mercado encima. Entra a **Mercado** desde el menú para elegir ciudades, fuentes y consultar los precios sincronizados de Américas.
- En **Acumulado**, pulsa **Borrar todos los lotes** y confirma para vaciar el plan, incluso si tienes filtros activos. Se conservan los precios, las cotizaciones y las cantidades que ya marcaste como compradas. Para reiniciar estas cantidades, usa **Poner todo a 0** cuando haya materiales en el plan.
- El borrado completo no se puede deshacer con el botón de borrado individual. Si quieres conservar una copia antes de vaciar el plan, usa **Descargar respaldo JSON**.

En la edición PC abre `INICIAR_WINDOWS.bat`. Para una web alojada, actualiza el servicio con **Solo Web V67**. Los pasos de [sincronización de V66](SINCRONIZAR_API_V66.md) siguen vigentes.
